# Portfolio redesign / Scrollcraft build brief

**Status:** Self-authored from the user's extensive conversation instructions, not a separate design interview. Source claims are grounded in the existing CV and GitHub case studies.

## Existing user direction
- Make the personal site "more alive" using Nate Herk's scroll skill.
- Replace the existing image logo, which the user dislikes.
- Position the user's combination of business, behavioural economics, and AI product delivery; prioritize getting remote employment.
- Keep the presentation visual, not too text-heavy; demonstrate AptTick as the most fully functional product.
- The video demo and live career outreach will be added when ready; do not invent a Loom link.

## Creative decisions
1. **Vibe:** premium, kinetic, editorial, direct, confident.
2. **Visitor journey:** a promise → skills synthesis → grounded commercial work → AptTick case study → secondary projects → a useful workflow diagnostic → contact.
3. **Energy curve:** powerful first viewport → quieter cognitive understanding → credibility / clarity → one engineered peak for AptTick → selective breadth → practical agency → decisive close.
4. **Peak:** "I could actually interact with the sort of AI product he builds." AptTick act, with a clearly labelled illustrative workflow switcher. Live AptTick and detailed evidence are external links.
5. **Signature move:** a behavioural economics-inspired mini workflow diagnostic. Clicking a real bottleneck changes the process intervention and principle, while preserving a single 3-step skeleton.
6. **Aesthetic family:** premium dark editorial with sea-glass green accent, a custom dimensional process hero, type as primary identity.
7. **Grammar:** chaptered editorial with independently moving physical planes, pinned three-part personal proposition, real evidence, interactive product showcase, a horizontal selected-work gallery, a live diagnostic and held ending. No generic video scroll scrubbing without genuine media.
8. **Assets:** Existing site copy and image-logo path were inspected through the user's browser; public CV, verified AptTick case study, GitHub documents, and project websites. Avoid unverified photography and fake product screenshots.

## Site feeling curve
- Recognition: "This person understands AI value" from one-screen clear promise and physical diagram.
- Confidence: "Three useful disciplines in one person" from the pinned reveal.
- Trust: sourced and properly attributed outcome labels.
- Peak: AptTick interactive workflow scene accompanied by links to real proof.
- Breadth: other commercial and AI workflows with accurate statuses.
- Agency: choose the pain point and see the implementation response.
- Closure: a single email CTA; same action in header and footer.

## Evidence boundaries
AptTick coaching, three-turn role-play and persistent feedback were verified on an owner/test-learner session 26 October 2026. Any in-site UI drawing is expressly labelled an illustration, not a screenshot. This is not proof of completed placements, accreditation or user adoption. Mora Engine owner flows are verified; full paid access is not. RemoteLaunch kit is live; software workspace remains under development. Commercial numbers are self-reported CV facts and are not attributed to AI products.

## Fingerprint
- Grammar: chaptered editorial
- Navigation: fixed name wordmark and anchored sections
- Hero: independently parallaxing papers, workflow core and outcome
- Sequence: flow / pin / flow / interactive live surface / pan / flow / pin
- Close: one held invitation, contact links underneath
- Signature move: selectable "operational bottleneck diagnostic"
